```bash
~/.config/herd/bin/php85/php.exe ~/.config/herd/bin/composer.phar update laravel/framework --with-all-dependencies
```

No constraint changed, no `uclemmer/*` package moved, and no application code

## 1. Why

On 2026-11-18, sessions working in other apps found `composer audit` reporting
CVE-2026-128083 against `laravel/framework` below `13.40.0`. It is a low-severity
advisory about Concurrency task output injection, reported 2026-11-13. The
owner asked for every app except `ckbs` to move to 13.43.

**This app was already outside the affected range.** `composer audit --locked`
on `13.42.0`, which doc 28 took on 2026-11-10, reported no advisories. The update
is for consistency across the workspace, not a fix this app needed.
